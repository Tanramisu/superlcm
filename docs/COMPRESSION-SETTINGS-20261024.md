## 最终行为

- 导航为“对话 / 工具 / 压缩 / 设置”。Claude Code、Pi、dsh 在“压缩”页分别配置，使用相同的比例预设、自定义输入、准备点提示及后台模型选择结构。
- 工具卡片默认说明改为“约 70% 时一次生成分块与上层摘要。”；自定义比例后显示相应准备点。
- 准备点 = 替换点 − 10 个百分点。默认70%/80%；50%替换对应40%准备。页面范围11%–99%，确保始终有正的提前准备区间。容量保护仍可更早准备或暂停请求。
- 默认使用会话模型。开启“允许其他模型”后，目录来自对应工具，只有后台模型改变。Claude 使用原生 CLI 的模型参数，Pi 使用原生注册表，dsh 使用宿主原生供应商/账号。另一模型容不下完整对话时拒绝分支，保留原文；不自动裁剪或切到其他摘要方式。
- 模型/模式/比例变更会使相关准备状态失效。Pi 保留已选原生后台模型，普通比例保存不把它清空。
- 模型目录查询后，在写事务内复核设置，防止其他进程刚关闭摘要却被旧请求重新打开。DSH 压缩表单的版本也包含共享摘要方式和接入版本；旧表单不能跨摘要方式变更覆盖新设置。
- Claude 的比例设置恢复旧接管人为设置的窗口上限，改用原生容量及用户原有上限，并设置原生压缩百分比；关闭接管时恢复原设置。旧绝对 token 门槛在保存新比例前保持兼容，CLI 的绝对值配置仍可用。
