# DSH 压缩恢复修复

此补丁修复 DSH 接管压缩中的已完成草稿提交问题，与 DSH 独立版 0.5.31 同步。Claude、Codex 的压缩流程不由本补丁改动。

后台后续分块或合并失败时，已完成的前缀可能无法达到整轮提交条件，导致请求反复报摘要未就绪。紧急压力下，只有已完成前缀通过来源、工具边界、当前用户输入、模型和设置核验，并且预计提交后低于正常替换阈值，才允许一次提交。未完成范围仍保留原文；正常准备阶段不替换上下文。提交后取消在途后继，拒绝其迟到结果。

持久化草稿不保存重复的供应商流。恢复后提交会省略相应流字段，避免原生 DSH 严格 JSON 校验拒绝 undefined。

新增八项离线原生宿主回归覆盖失败恢复、持久化与树重建、摘要预算不足、非紧急不提前替换、空间仍不足时拒绝放行、来源和当前输入保护、模型切换、取消晚结果。所有响应均为本地合成数据，无付费调用。真实供应商的后续回复需要在实际会话重试后确认。
